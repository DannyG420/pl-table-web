# PL Table (web app)

Installable PWA version of PL Table — free to use on iPhone without the App Store.
**Open https://dannyg420.github.io/pl-table-web/ in Safari → Share → Add to Home Screen.**

Static files only (no server, no keys). Data from ESPN's public JSON and FotMob ratings, both of which allow
cross-origin requests. Favourites and predictions are stored in the browser (localStorage) on each device.

Made by Danny G.
